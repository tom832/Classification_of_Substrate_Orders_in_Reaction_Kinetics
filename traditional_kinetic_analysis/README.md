# Traditional kinetic analysis for Table S13

This folder supplies the experimental input, calculation scripts, key result tables and a combined figure report for the seven-substrate analysis.

## Run the calculation

Use the main `cosork` environment, or install the separate dependencies with `pip install -r requirements.txt`. Run from this directory:

```bash
python code/check_numerics.py
python run_analysis.py --out rerun_results --workers 4
```

The full calculation writes a new directory and includes 42 processing configurations and 5,600 bootstrap replicates. The input and settings are `input_data_current.csv` and `analysis_plan.json`.

The primary configuration is `tail10__sg21_stride7__floor0.05`. All sensitivity configurations are retained in these summaries. Individual bootstrap draws and intermediate audit files are generated by `run_analysis.py` when needed.

`all_substrates_fits_and_diagnostics.pdf` contains four pages: primary rate fits, whitened residuals, processing sensitivity, and the direct-concentration comparison. Regenerate it with:

```bash
python plot_and_validate.py
# Use newly calculated results:
python plot_and_validate.py --results rerun_results --output rerun_results/kinetic_report.pdf
# Optional detailed diagnostic figures:
python plot_and_validate.py --full_diagnostics --individual_figures
```

The default plotting command writes only the combined PDF. The optional flags add the mathematical control, individual-substrate residual panels, and separate PNG/PDF files.

## Method and references

The primary analysis uses 21-point quadratic local-polynomial differentiation with stride 7, a final-10%-median offset, and a 5% normalized-concentration cutoff. All five candidate laws are fitted on the same rate scale by generalized least squares (GLS), using covariance propagated from overlapping windows. Centered R² and the corrected Akaike information criterion (AICc) summarize fit quality and model complexity. Background and window sensitivity accompany the primary results.

The references below are also cited in SI Section 10 and in the calculation scripts:

1. **Local-polynomial differentiation:** Savitzky and Golay, *Anal. Chem.* **1964**, *36*, 1627–1639. [DOI: 10.1021/ac60214a047](https://doi.org/10.1021/ac60214a047).
2. **Small-sample AIC correction:** Hurvich and Tsai, *Biometrika* **1989**, *76*, 297–307. [DOI: 10.1093/biomet/76.2.297](https://doi.org/10.1093/biomet/76.2.297).
3. **Kinetic model discrimination:** Taylor et al., *React. Chem. Eng.* **2021**, *6*, 1404–1411. [DOI: 10.1039/D1RE00098E](https://doi.org/10.1039/D1RE00098E).

The fitted laws, background treatment and error model are specified in `analysis_plan.json` and the SI. The S4 numerical check retains the factor of two between productive flux and substrate disappearance when both substrate-consuming steps are included. Machine-learning dataset preparation is in `../prepare_data_S1_S5.ipynb`.
